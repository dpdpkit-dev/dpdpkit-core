# dpdpkit

Developer toolkit for India's Digital Personal Data Protection Act, 2023 and DPDP Rules, 2025:
consent ledger, versioned notices, rights requests, retention and erasure, audit evidence.

```bash
pip install dpdpkit              # core + policy packs + CLI
pip install "dpdpkit[fastapi]"   # + FastAPI adapter
```

> **Disclaimer.** dpdpkit helps you implement obligations under the DPDP Act and Rules. It does not
> provide legal advice and does not guarantee compliance.

See https://github.com/dpdpkit-dev for documentation and source.
